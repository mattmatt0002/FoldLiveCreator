# FoldLiveCreator

Starter Android project for a general-purpose live wallpaper creator focused on foldables such as the Galaxy Z Fold series.

## Current starter
- Native Android app shell
- Kotlin
- Min SDK 29
- Target/compile SDK 35
- GitHub Actions workflow that builds a debug APK and uploads it as an artifact

## Planned direction
- Import an image
- Add layered motion, lighting, atmosphere, particles, and masked effects
- Separate cover-screen and inner-screen compositions
- Save reusable projects
- Export live wallpaper output for Android

## Cloud build
Push to `main` or run **Actions → Build Android APK → Run workflow**.
Download the `FoldLiveCreator-debug-apk` artifact after the build completes.
